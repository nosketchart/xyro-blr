# XYRO BANGALORE (@xyro.blr) ⚡
> **Bangalore's Next Wave: Events • Music • Madness**

Official front-end web application for **Xyro** (`@xyro.blr`), Bangalore's premier nightlife collective, sunset session curator, pool party organizer, and electronic music movement.

---

## 🌟 Features

* **Multi-Page Architecture:** Dedicated routes for Home, Events, Express Guestlist, VIP Tables, Sound & DJs, The Vibe Gallery, Partner/Host, and Nightlife FAQs.
* **Instant Digital QR Pass Generator:** Solves manual Instagram DM bottlenecks. Attendees register and instantly receive a verified digital entry QR pass with confetti burst and 1-click WhatsApp share.
* **VIP Table & Cabana Concierge:** High-roller packages with interactive table location selector and pre-populated WhatsApp concierge triggers.
* **Resident Sound Room & Audio Synth:** Interactive music console featuring resident DJs (`@s1rcar`, `@txrunreddy._`, `@adxu.u`, `@shaurya__26310`), plus a toggleable 124 BPM Web Audio electronic beat synthesizer.
* **B2B & Campus Promoter Portal:** Lead capture for venue takeovers, brand sponsorships, and student campus ambassadors.
* **The Vibe Archive:** Filterable media gallery with fullscreen lightbox and direct sync bridge to `@xyro.blr`.

---

## 🛠️ Tech Stack

* **Framework:** React 18 + Vite
* **Routing:** React Router v6
* **Styling:** Tailwind CSS (Cyberpunk dark theme, glassmorphism, neon glows)
* **Icons:** Lucide React
* **QR Codes:** `qrcode` client-side generator
* **Effects:** `canvas-confetti` + Web Audio API synthesizer

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
